Política de Privacidad

Última actualización: 11 de octubre de 2026

1. Introducción

DocVault es una aplicación independiente diseñada para organizar, almacenar y consultar documentos personales de manera privada y segura.

La aplicación funciona localmente en el dispositivo y no requiere crear una cuenta de usuario.

2. Almacenamiento de información

Los documentos PDF, imágenes digitalizadas, categorías, fechas y demás información proporcionada por el usuario se almacenan localmente en el dispositivo.

DocVault no transmite estos documentos a servidores operados por su desarrollador.

3. Cámara y archivos

DocVault puede solicitar acceso a la cámara para digitalizar documentos.

También permite importar archivos seleccionados mediante las herramientas del sistema operativo. Estos accesos se utilizan para las funciones solicitadas por el usuario.

4. Reconocimiento de texto

DocVault utiliza tecnologías de reconocimiento de texto disponibles en el dispositivo para facilitar la clasificación y búsqueda de documentos.

Este procesamiento se realiza localmente, sin enviar el contenido a servidores del desarrollador.

5. Seguridad y autenticación

La aplicación utiliza mecanismos de seguridad proporcionados por iOS, incluyendo almacenamiento protegido y autenticación mediante Face ID o Touch ID cuando corresponda.

Los datos biométricos son administrados por el sistema operativo. DocVault no recibe ni almacena información biométrica del usuario.

6. Respaldos cifrados

Los usuarios pueden crear respaldos cifrados mediante archivos con extensión .docvault, protegidos con contraseña y cifrado AES-256.

Cada usuario decide dónde almacenar o compartir sus respaldos.

7. Recopilación de datos

DocVault no requiere registro de usuario y no recopila información personal para transmitirla al desarrollador.

La aplicación no incorpora sistemas de rastreo publicitario ni vende información de sus usuarios.

8. Servicios de terceros

Si el usuario comparte documentos o respaldos mediante otras aplicaciones o servicios, el tratamiento posterior de esos archivos dependerá de las políticas de dichos servicios.

9. Control de los documentos

El usuario puede administrar y eliminar sus documentos desde DocVault.

La eliminación de la aplicación puede ocasionar la pérdida de información almacenada localmente si no existe un respaldo independiente.

10. Actualizaciones y contacto

Esta política podrá actualizarse para reflejar cambios en las funcionalidades de DocVault o en los requisitos aplicables.

Para consultas sobre privacidad: contacto.docvault@gmail.com

Privacy Policy

Last updated: October 11, 2026

1. Introduction

DocVault is an independently developed application designed to organize, store, and access personal documents privately and securely.

The application operates locally on the device and does not require users to create an account.

2. Information Storage

PDF documents, scanned images, categories, dates, and other user-provided information are stored locally on the device.

DocVault does not transmit these documents to servers operated by its developer.

3. Camera and Files

DocVault may request camera access to scan documents.

Users may also import files using the operating system's file-selection tools. These permissions support features requested by the user.

4. Text Recognition

DocVault uses on-device text recognition technologies to assist with document classification and search.

Processing takes place locally without sending document contents to the developer's servers.

5. Security and Authentication

DocVault uses security mechanisms provided by iOS, including protected storage and Face ID or Touch ID authentication where applicable.

Biometric information is managed by the operating system. DocVault does not receive or store users' biometric data.

6. Encrypted Backups

Users can create password-protected backups using .docvault files encrypted with AES-256.

Users control where their backup files are stored or shared.

7. Data Collection

DocVault does not require user registration and does not collect personal information for transmission to its developer.

The application does not include advertising tracking systems or sell user information.

8. Third-Party Services

If users share documents or backups through other applications or services, subsequent processing is subject to the policies of those services.

9. User Control

Users can manage and delete their documents within DocVault.

Deleting the application may result in the loss of locally stored information unless an independent backup has been retained.

10. Updates and Contact

This policy may be updated to reflect changes to DocVault or applicable requirements.

For privacy-related inquiries: contacto.docvault@gmail.com
